# Add Tutelr technology programs page

## Goal
Add a new category named “Cybersecurity / AI / Embedded Robotics” inside the header’s Programs menu, with “Tutelr” beneath it linking to a dedicated page.

## Implementation
1. Add a third category to the Programs menu after the existing Diploma and UG Degree groups.
2. Create a responsive Tutelr page using the existing BSDT navigation, footer, colors, and technology imagery.
3. Present Cybersecurity, Artificial Intelligence, and Embedded Robotics as three clear learning areas without inventing dates, pricing, credentials, or placement claims.
4. Add a route for the page and page-specific search/social metadata.
5. Ensure the enlarged Programs menu remains usable on desktop and mobile.
6. Verify the new menu link, page rendering, and current build status.

## Technical details
- Proposed page URL: `/tutelr`
- The page will reuse existing local Cybersecurity and Robotics assets to keep the site lightweight.
- “Embedded” will use the standard spelling on the published interface.
